Install & Run

Install using the official ZScript installer.

Install

# Linux / macOS
curl -fsSL https://zscript.us.kg/install.sh | bash

# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -Command "irm https://zscript.us.kg/install.ps1 | iex"

Why ZScript?

🔥 Compile-Time Execution

Run ZScript during compilation. Generate code, read files, call APIs. Full Bun and Node.js Api Supported.

🛡 Strong Type System

Nominal types, interfaces, generics, async checking, and more.

⚡ Bun Native

Embedded Bun runtime. No extra tooling required.

🧩 Modern Features

defer(LIFO), queue(FIFO), match, pipelines, compile-time macros.

🌍 JS Ecosystem

Use Node, npm, Bun, Javascript packages directly.

🚀 Fast Workflow

Build, run, and ship with one tool: zsc.
